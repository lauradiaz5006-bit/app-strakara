thème 2

🔢 Suites géométriques

Terminale Bac Pro — groupement B

← Retour aux thèmes

Le cours

Une suite géométrique est une liste de nombres où on passe d'un terme au suivant en multipliant toujours par le même nombre, appelé raison q (ici toujours positive).

  • Premier terme : u₀
  • Terme de rang n : uₙ = u₀ × qⁿ
  • Sens de variation : si q > 1, la suite augmente ; si 0 < q < 1, elle diminue ; si q = 1, elle reste constante.
  • Somme des n+1 premiers termes (de u₀ à uₙ) : Sₙ = u₀ × (qⁿ⁺¹ − 1) / (q − 1) (si q ≠ 1)

Exemple : u₀ = 3, q = 2. u₃ = 3 × 2³ = 3 × 8 = 24.

Contexte pro : une pièce de bois qui perd 10 % de sa valeur chaque année suit une suite géométrique de raison q = 0,9.

Méthode : étape par étape

  1. Repérer le premier terme u₀ et la raison q (q > 0 ici). Astuce : q = u₁ / u₀ (un terme divisé par le précédent).
  2. Pour calculer un terme de rang n : uₙ = u₀ × qⁿ (on multiplie u₀ par q, n fois).
  3. Pour le sens de variation, regarder uniquement q : q > 1 → ça augmente, 0 < q < 1 → ça diminue.
  4. Pour une somme de termes, utiliser directement la formule Sₙ (ne jamais additionner les termes un par un si n est grand).

Exemple 2 (reconnaître q et vérifier) : une entreprise facture 5 000 € la 1ère année. Son chiffre d'affaires est multiplié par 1,5 chaque année. Quel est le CA de la 3e année (u₂, car u₀ = 1ère année) ?
u₀ = 5000, q = 1,5. u₂ = 5000 × 1,5² = 5000 × 2,25 = 11 250 €.
Vérification intermédiaire : u₁ = 5000 × 1,5 = 7 500 € (2e année), u₂ = 7500 × 1,5 = 11 250 € (3e année) — même résultat, deux méthodes.

⚠️ Pièges fréquents

  • Confondre le rang n et le nombre d'années/multiplications : u₀ est le premier terme (souvent l'année de départ), donc après n années on est à uₙ, pas uₙ₊₁.
  • Oublier que q peut être inférieur à 1 (ex. une perte de valeur) : la suite est alors décroissante, même si elle reste positive.
  • Confondre suite géométrique (on multiplie par q) et suite arithmétique (on ajoute une raison r) — ici on multiplie toujours.
  • Calculer la somme en additionnant les termes un par un au lieu d'utiliser la formule Sₙ.

✅ Ce qu'il faut retenir

  • uₙ = u₀ × qⁿ — on multiplie, on n'ajoute jamais.
  • q > 1 → la suite augmente ; 0 < q < 1 → elle diminue.
