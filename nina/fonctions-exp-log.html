🌱 Exponentielle & logarithme

Terminale Bac Pro — groupement B

← Retour aux thèmes

Le cours

1. Fonction exponentielle de base q

Une fonction de la forme f(x) = qˣ (avec q > 0) sert à modéliser une évolution qui se répète toujours dans les mêmes proportions (comme une suite géométrique, mais pour n'importe quel x, pas seulement des entiers).

  • Si q > 1 : f est croissante (évolution à la hausse).
  • Si 0 < q < 1 : f est décroissante (évolution à la baisse).
  • Propriété utile : qˣ⁺ʸ = qˣ × qʸ.

2. Logarithme décimal (log)

Le logarithme décimal sert à « inverser » une puissance : il permet de retrouver x quand on connaît qˣ.

  • log(qˣ) = x × log(q)
  • log(a × b) = log(a) + log(b)
  • log(a / b) = log(a) − log(b)
  • log(1) = 0, log(10) = 1

Exemple : log(2) ≈ 0,301 et log(5) ≈ 0,699. Alors log(10) = log(2×5) = log(2) + log(5) = 0,301 + 0,699 = 1 ✓ (cohérent, car log(10) = 1).

Méthode : résoudre qˣ = a, étape par étape

  1. Passer au logarithme décimal des deux côtés de l'égalité : log(qˣ) = log(a).
  2. Utiliser la propriété log(qˣ) = x × log(q).
  3. On obtient x × log(q) = log(a).
  4. Isoler x : x = log(a) / log(q).
  5. Calculer la valeur avec les log donnés (ou à la calculatrice).

Exemple complet (contexte pro) : le chiffre d'affaires d'une entreprise augmente de 8 % par an. Après combien d'années aura-t-il doublé ? On cherche x tel que 1,08ˣ = 2.
x × log(1,08) = log(2) → x = log(2) / log(1,08) ≈ 0,301 / 0,033 ≈ 9,0 années (on arrondit à l'année supérieure si besoin : 9 ans).

⚠️ Pièges fréquents

  • Confondre log(a + b) avec log(a) + log(b) : c'est faux, la propriété d'addition n'existe que pour un produit (log(a×b)), jamais pour une somme.
  • Écrire log(aⁿ) = (log a)ⁿ au lieu de log(aⁿ) = n × log(a).
  • Oublier qu'un taux d'évolution de +8 % correspond à un coefficient multiplicateur q = 1,08 (pas 0,08).
  • Le logarithme d'un nombre négatif ou nul n'existe pas — toujours vérifier que a > 0.

✅ Ce qu'il faut retenir

  • log(qˣ) = x × log(q).
  • Pour résoudre qˣ = a : x = log(a) / log(q).
