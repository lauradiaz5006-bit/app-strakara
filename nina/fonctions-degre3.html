Le cours

Une fonction polynôme de degré 3 s'écrit f(x) = ax³ + bx² + cx + d. Elle sert par exemple à modéliser un volume, un coût ou une quantité qui varie de façon plus complexe qu'une droite.

Calculer une image : pour calculer f(x) pour une valeur donnée, on remplace x par cette valeur et on calcule.

Exemple : f(x) = x³ − 3x. f(2) = 2³ − 3×2 = 8 − 6 = 2.

La dérivée f'(x) permet d'étudier les variations de f sans tracer la courbe. Règle à connaître : la dérivée de ax³ est 3ax², la dérivée de bx² est 2bx, la dérivée de cx est c, et la dérivée d'une constante d est 0. Donc si f(x) = ax³ + bx² + cx + d, alors f'(x) = 3ax² + 2bx + c.

Exemple : f(x) = x³ − 3x. f'(x) = 3x² − 3. Pour x = 2 : f'(2) = 3×4 − 3 = 9.

Variations : le signe de f'(x) donne le sens de variation de f : là où f'(x) > 0, f est croissante ; là où f'(x) < 0, f est décroissante. On résume ça dans un tableau de variations. Un point où f' change de signe est un extremum local (un maximum ou un minimum).

Contexte pro : le volume d'un tiroir dont on fait varier une dimension x peut être modélisé par une fonction f(x) de degré 3. Étudier ses variations permet de trouver la dimension qui donne le volume maximal.
