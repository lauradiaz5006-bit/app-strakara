Le cours

1. Dérivée d'une fonction polynôme de degré 3

Une fonction de la forme f(x) = a·x³ + b·x + c (avec a ≠ 0) est une fonction polynôme de degré 3. Pour étudier ses variations, on utilise sa dérivée f'(x).

  • Règle : la dérivée de a·xⁿ est n × a·xⁿ⁻¹.
  • La dérivée d'une constante c est 0.
  • Donc pour f(x) = a·x³ + b·x + c, on a f'(x) = 3a·x² + b.

Exemple : f(x) = x³ − 3x + 2. Alors f'(x) = 3x² − 3.

2. Signe de f'(x) et variations de f

  • Si f'(x) > 0 sur un intervalle, alors f est croissante sur cet intervalle.
  • Si f'(x) < 0 sur un intervalle, alors f est décroissante sur cet intervalle.
  • Si f'(x) = 0 et que f' change de signe en ce point, f admet un extremum local (maximum ou minimum) à cet endroit.

Méthode : étudier les variations de f, étape par étape

  1. Calculer f'(x) à partir de f(x) (dériver terme à terme).
  2. Résoudre f'(x) = 0 pour trouver les valeurs de x qui annulent la dérivée.
  3. Étudier le signe de f'(x) avant et après ces valeurs (tableau de signes).
  4. En déduire les variations de f : f' positif → f croît ; f' négatif → f décroît.
  5. Calculer f(x) aux valeurs trouvées pour obtenir les extremums locaux.

Exemple complet : f(x) = x³ − 3x + 2, donc f'(x) = 3x² − 3 = 3(x² − 1) = 3(x − 1)(x + 1).
f'(x) = 0 pour x = −1 ou x = 1.
Pour x < −1 : f'(x) > 0 (f croît). Entre −1 et 1 : f'(x) < 0 (f décroît). Pour x > 1 : f'(x) > 0 (f croît).
Extremum en x = −1 (maximum local) : f(−1) = (−1)³ − 3×(−1) + 2 = −1 + 3 + 2 = 4.
Extremum en x = 1 (minimum local) : f(1) = 1³ − 3×1 + 2 = 1 − 3 + 2 = 0.

Contexte pro : le bénéfice B(x) d'un atelier (en milliers d'euros) selon la quantité produite x (en dizaines de pièces) peut se modéliser par une fonction de ce type : étudier ses variations permet de trouver la quantité à produire pour maximiser le bénéfice.

⚠️ Pièges fréquents

  • Confondre f(x) et f'(x) : le signe qui donne les variations est celui de la dérivée, pas celui de f.
  • Oublier de changer de signe de part et d'autre d'une racine de f'(x) : il faut toujours tester un signe de chaque côté, jamais le supposer.
  • Penser qu'un extremum local est forcément le plus grand (ou plus petit) de toute la fonction — « local » veut dire localement, pas sur tout l'intervalle.
  • Oublier le terme en b dans f'(x) = 3a·x² + b quand b ≠ 0.

✅ Ce qu'il faut retenir

  • f(x) = a·x³ + b·x + c → f'(x) = 3a·x² + b.
  • f'(x) > 0 → f croît ; f'(x) < 0 → f décroît ; f'(x) = 0 avec changement de signe → extremum local.
