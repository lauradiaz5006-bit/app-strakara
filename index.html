Le principe

Les premières fiches doivent donner envie de rejoindre le réseau.

Au lancement, le but n’est pas de montrer un gros nombre. Le but est de créer des profils sérieux, visibles et utiles pour les autres entreprises.

Phase de lancement

Profil → validation → publication → visibilité.

Les profils ne sont pas affichés comme un simple annuaire vide : ils sont créés, vérifiés, puis publiés progressivement pour donner une image sérieuse dès le départ.

01Profil

L’entreprise crée sa fiche professionnelle avec son activité, sa zone et ses ressources.

02Validation

STRAKARA vérifie les informations avant de rendre le profil visible.

03Publication

Les profils sont ajoutés progressivement dans la page entreprises.

04Mise en avant

Les premières entreprises peuvent être présentées dans les communications du lancement.

05Réseau

Plus le réseau grandit, plus les mises en relation deviennent utiles.
